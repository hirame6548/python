# 問題文

出典: https://atcoder.jp/contests/awc0144/tasks/awc0144_d

配点 : $400$ 点

## 問題文

高橋君は花火大会の演出を担当しています。夜空には $N$ 発の花火が打ち上げ準備されており、それぞれ $1$ から $N$ までの番号が付いています。

各花火には、打ち上げ準備中・打ち上げ済み・消滅 の $3$ つの状態があります。最初、すべての花火は打ち上げ準備中の状態です。

各花火 $i$（$1 \leq i \leq N$）には「衝撃波の対象」となる花火番号 $T_i$ が設定されています（$T_i \neq i$）。

青木君は演出家として、花火を一発ずつ選んで打ち上げる順番を決めます。具体的には、以下の手順で花火大会が進みます。

1. 青木君は打ち上げ準備中の花火の中から $1$ 発を選び、打ち上げる。打ち上げた花火の状態は打ち上げ済みとなり、演出リストの末尾に記録される。

1. 打ち上げた花火を $i$ とする。花火 $i$ の衝撃波の対象である花火 $T_i$ がまだ打ち上げ準備中であれば、花火 $T_i$ は暴発し、状態が消滅に変わる（演出リストには記録されない）。花火 $T_i$ がすでに打ち上げ済みまたは消滅であれば、何も起こらない。

1. 打ち上げ準備中の花火が $1$ 発以上残っていれば手順 1 に戻る。打ち上げ準備中の花火がなくなったら花火大会は終了する。

注意： 消滅した花火は打ち上げることができません。また、消滅した花火が衝撃波を発することはなく、消滅によって連鎖的に他の花火が暴発することはありません。

花火大会が終了すると、演出リストが確定します。青木君は、演出リストに記録される花火の数（すなわち、打ち上げ済みとなった花火の数）をできるだけ多くしたいと考えています。

青木君が最適に花火を選んだとき、演出リストに記録される花火の数の最大値を求めてください。

## 制約

- $2 \leq N \leq 10^6$

- $1 \leq T_i \leq N$（$1 \leq i \leq N$）

- $T_i \neq i$（$1 \leq i \leq N$）

- 入力はすべて整数である。

## 入力

$N$<br>
$T_1 \quad T_2 \quad \cdots \quad T_N$

- $1$ 行目には、花火の数 $N$ が与えられる。

- $2$ 行目には、各花火 $i$（$1 \leq i \leq N$）の衝撃波の対象を表す花火番号 $T_i$ が、スペース区切りで $N$ 個与えられる。

## 出力

青木君が最適に行動したときの、演出リストに記録される花火の数の最大値を $1$ 行で出力せよ。
