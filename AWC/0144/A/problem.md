# 問題文

出典: https://atcoder.jp/contests/awc0144/tasks/awc0144_a

配点 : $233$ 点

## 問題文

高橋君を含む $N$ 人のグループが遊園地にやってきました。この遊園地には $M$ 個のアトラクションがあります。

グループのメンバーにはそれぞれ身長があり、メンバー $j$ $(1 \leq j \leq N)$ の身長は $L_j$ cm です。また、各アトラクションには身長制限が設けられており、アトラクション $i$ $(1 \leq i \leq M)$ に乗るには身長が $S_i$ cm 以上でなければなりません。すなわち、メンバー $j$ がアトラクション $i$ に乗れるのは $L_j \geq S_i$ を満たすときに限ります。

高橋君は、グループの $N$ 人全員が身長制限を満たして乗ることのできるアトラクションがいくつあるか知りたいと思っています。すなわち、すべてのメンバー $j$ $(1 \leq j \leq N)$ について $L_j \geq S_i$ が成り立つようなアトラクション $i$ の個数を求めてください。

## 制約

- $1 \leq N \leq 2 \times 10^5$

- $1 \leq M \leq 2 \times 10^5$

- $1 \leq L_j \leq 300$ $(1 \leq j \leq N)$

- $1 \leq S_i \leq 300$ $(1 \leq i \leq M)$

- 入力はすべて整数

## 入力

$N \quad M$<br>
$L_1 \quad L_2 \quad \ldots \quad L_N$<br>
$S_1 \quad S_2 \quad \ldots \quad S_M$

- $1$ 行目には、グループの人数を表す整数 $N$ と、アトラクションの数を表す整数 $M$ が、スペース区切りで与えられる。

- $2$ 行目には、各メンバーの身長（cm）を表す整数 $L_1, L_2, \ldots, L_N$ が、スペース区切りで与えられる。

- $3$ 行目には、各アトラクションの身長制限（cm）を表す整数 $S_1, S_2, \ldots, S_M$ が、スペース区切りで与えられる。

## 出力

グループの $N$ 人全員が乗ることのできるアトラクションの数を $1$ 行で出力してください。

