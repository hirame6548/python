# 問題文

出典: https://atcoder.jp/contests/awc0144/tasks/awc0144_b

配点 : $300$ 点

## 問題文

高橋君は、とある名門オーケストラの入団オーディションに参加しています。オーディションには $N$ 人の候補者が参加しており、それぞれ $1$ から $N$ の番号が付けられています。高橋君の番号は $1$ です。

オーディションでは、各候補者に実技の得点が付けられます。候補者 $i$ $(1 \leq i \leq N)$ の得点は $S_i$ 点です。

ところが、結果発表の直前になって、$M$ 人の候補者が辞退届を提出しました。辞退した候補者の番号は $D_1, D_2, \ldots, D_M$ です。高橋君は辞退しません（すなわち、$D_j \neq 1$ が保証されます）。

辞退した候補者を除外した残りの候補者は、得点が高い順に順位付けされます。得点が同じ候補者が複数いる場合は、番号が小さい候補者ほど上位とします。このルールにより、残りの候補者全員に一意な順位が定まります。この順位付けにおいて上位 $K$ 人が合格となります。

なお、辞退者を除外した後の候補者の人数は $K$ 人以上であることが保証されます。

高橋君が合格できるかどうかを判定してください。

## 制約

- $1 \leq N \leq 2 \times 10^5$

- $1 \leq K \leq N$

- $0 \leq M \leq N - 1$

- $K \leq N - M$

- $0 \leq S_i \leq 10^9$ $(1 \leq i \leq N)$

- $1 \leq D_j \leq N$ $(1 \leq j \leq M)$

- $D_j \neq 1$ $(1 \leq j \leq M)$

- $D_1, D_2, \ldots, D_M$ はすべて異なる

- 入力はすべて整数

## 入力

$N \quad K \quad M$<br>
$S_1 \quad S_2 \quad \ldots \quad S_N$<br>
$D_1 \quad D_2 \quad \ldots \quad D_M$

- $1$ 行目には、候補者の人数 $N$ 、合格人数 $K$ 、辞退者の人数 $M$ が、スペース区切りで与えられる。

- $2$ 行目には、候補者 $1, 2, \ldots, N$ の得点 $S_1, S_2, \ldots, S_N$ が、スペース区切りで与えられる。

- $3$ 行目には、辞退した候補者の番号 $D_1, D_2, \ldots, D_M$ が、スペース区切りで与えられる。ただし、$M = 0$ の場合、$3$ 行目は与えられない（入力は $2$ 行のみからなる）。

## 出力

高橋君（候補者 $1$ ）が合格できる場合は Yes を、できない場合は No を $1$ 行で出力せよ。

## 入力例 1

```text
5 2 1
80 100 90 70 60
2
```

## 出力例 1

```text
Yes
```

## 入力例 2

```text
7 3 0
85 90 85 85 70 60 50
```

## 出力例 2

```text
Yes
```

## 入力例 3

```text
10 2 3
30 95 88 76 100 60 92 55 40 85
4 6 8
```

## 出力例 3

```text
No
```
